# Filo Yönetim V2

Tek kullanıcı için geliştirilen, web tabanlı filo yönetim uygulaması.

## Teknoloji
- React
- Vite
- Supabase PostgreSQL
- Supabase Auth
- Supabase Storage
- Responsive / PWA hedefi

## Amaç
Mevcut `filo-takip-v1-backup.html` prototipini gerçek veritabanlı bir uygulamaya taşımak.

## Güvenlik
Supabase RLS aktif olacak. Kullanıcı sadece kendi şirketine bağlı verilere erişecek.

Kurulum: `SETUP.md`
